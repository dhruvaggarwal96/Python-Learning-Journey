# Day 28 — COVID-19 Data Visualization

## 📅 90-Day Data Scientist + Internship Roadmap

Today I focused on learning **Data Visualization with Matplotlib** using a real-world COVID-19 dataset.

Although I couldn't complete the entire project, I spent time understanding how to choose the correct visualization for different types of data. This helped me realize that creating meaningful charts is more than just writing code—it requires understanding the data first.

## 📈 Visualizations Practiced

- Line Chart
- Bar Chart
- Histogram
- Pie Chart

I also learned why some charts become difficult to interpret when the data contains multiple countries and how grouping or filtering the data is necessary before visualization.

---

## 💡 Key Learnings

- Every chart should answer a specific question.
- The X-axis and Y-axis should be chosen based on the analysis objective.
- Time-series data should generally use Line Charts.
- Data often needs to be grouped or filtered before plotting.
- Good visualization is about communicating insights, not just creating graphs.

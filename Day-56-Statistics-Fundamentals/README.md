## 🧠 Key Learnings

* **Mean** represents the average value and is sensitive to outliers.
* **Median** represents the middle value and is more robust to outliers.
* **Mode** represents the most frequently occurring value and multiple modes can exist.
* **Variance** measures how spread out the data is from the mean.
* **Standard Deviation** measures the average spread of observations around the mean.
* `describe()` provides a quick statistical summary of numerical features.

# Day 35 — Portfolio SQL Project | Blinkit Sales Analysis

## 📌 Overview

Welcome to **Day 35** of my **#90DaysOfCode** challenge!

Today's project focused on solving real-world business problems using SQL by analyzing a **Blinkit Sales** dataset. Instead of practicing isolated SQL concepts, I worked on a portfolio-style project that simulates the type of analysis a Data Analyst performs in an e-commerce company.

The project covers customer behavior, sales performance, product analysis, regional insights, and business reporting using SQL.

## 📊 Business Questions Solved

### Basic Analysis

* Calculate total revenue generated by Blinkit.
* Find the total number of orders.
* Find the total number of unique customers.
* Calculate the average order value.
* Identify the top 10 highest-spending customers.
* Calculate revenue generated by each city.
* Calculate revenue generated by each product category.
* Find the total quantity sold for every product.

### Intermediate Analysis

* Identify the month with the highest revenue.
* Find the top 5 best-selling products by quantity.
* Find the top 5 products generating the highest revenue.
* Calculate the average delivery time for each city.
* Find cities where the average delivery time exceeds 20 minutes.
* Calculate Customer Lifetime Value (CLV).
* Segment customers based on total spending.

### Advanced Analysis

* Identify repeat customers.
* Find customers whose spending is above the average customer spending.
* Identify the best-performing category in each city based on revenue.

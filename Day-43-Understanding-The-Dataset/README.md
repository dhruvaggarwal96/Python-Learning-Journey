## 🎯 Key Takeaways

* Always perform EDA before starting analysis.
* `df.info()` is one of the most useful functions for understanding a dataset.
* `df.describe()` summarizes only numerical columns by default.
* `df.shape` returns `(rows, columns)`.
* `df.sample()` provides a random view of the dataset.
* Understanding feature types is essential for choosing the right analysis techniques.

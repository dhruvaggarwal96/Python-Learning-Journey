# 🌍 Day 27 — World Happiness Report 2017 Visualization

## 📌 Overview

Today, I explored the World Happiness Report 2017 dataset and created multiple visualizations to understand the distribution of happiness and the factors associated with it.

This project focuses on data visualization using Matplotlib and Pandas.

---

## 📂 Dataset

World Happiness Report 2017

Columns used:

* Country
* Happiness.Score
* Economy..GDP.per.Capita.
* Family
* Health..Life.Expectancy.
* Freedom
* Generosity
* Trust..Government.Corruption.

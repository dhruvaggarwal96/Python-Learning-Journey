# Day 25 - Histograms

## Topics Covered
- Histograms
- Data Distribution
- Frequency Analysis
- Skewness
- Outlier Detection

## Practice Completed
- Age Distribution Histogram
- Student Marks Histogram
- Customer Age Histogram
- Employee Salary Histogram

## Key Learnings
- Histograms show how data is distributed.
- The tallest bar represents the most frequent range.
- Histograms help identify skewness and outliers.
- Bin size affects the appearance of the distribution.

## 📌 Overview

Today I learned how to analyze the distribution of numerical features using statistical techniques and visualizations. Understanding data distribution helps identify patterns, detect outliers, measure variability, and prepare data for machine learning models.

## 💼 Business Insights

* Identified features with the highest variability, indicating inconsistent customer behavior.
* Detected variables containing outliers that may require treatment before modeling.
* Compared mean and median to understand the effect of skewed distributions.
* Recognized stable features with low variability that are easier to predict.
* Determined which features may benefit from transformation before machine learning.

---

## 🚀 Key Takeaways

* Histograms reveal how values are distributed.
* KDE plots provide a smoother view of the distribution.
* Box plots make outlier detection quick and effective.
* Mean, median, and mode describe the center of the data in different ways.
* Variance and standard deviation measure how spread out the data is.
* Distribution analysis is a crucial step before feature engineering and model building.

# 📒 Notebooks

This folder contains the Jupyter Notebook used for the **Hotel Booking Demand Analysis** project.

## Notebook

- **Hotel_Booking_Demand_Analysis.ipynb**
  - Performs end-to-end Exploratory Data Analysis (EDA)
  - Includes dataset understanding and feature exploration
  - Covers data cleaning and preprocessing
  - Generates visualizations using Matplotlib and Seaborn
  - Extracts business insights and recommendations
  - Summarizes key findings, executive summary, conclusion, and future improvements

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Key Learnings

* Understood the importance of feature engineering in data preprocessing.
* Learned to create new numerical, categorical, and boolean features.
* Used `pd.cut()` to convert continuous values into meaningful categories.
* Used `np.where()` for simple conditional logic.
* Learned `np.select()` for handling multiple conditions efficiently.
* Practiced using `isin()` for checking membership in categorical data.
* Learned the difference between Python's `and` and Pandas' `&` operators.
* Built business-oriented features that can improve reporting and predictive models.

---

## 💼 Business Value

Feature engineering helps convert raw data into meaningful information that is easier to analyze and more useful for machine learning models. Business-driven features such as revenue, customer type, booking priority, and booking value make it easier to identify patterns, segment customers, and support better decision-making.

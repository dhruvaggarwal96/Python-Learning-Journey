# Day 63 – Logistic Regression & Introduction to Classification

## 📌 Overview

On **Day 63** of my **90-Day Data Science Journey**, I learned the fundamentals of **Classification** and built my first **Logistic Regression** model using the **Breast Cancer Wisconsin Dataset** from Scikit-learn.

This project covers the complete machine learning workflow, from understanding classification concepts to training and evaluating a Logistic Regression model.

## 📂 Dataset

**Breast Cancer Wisconsin Dataset**

* Source: `sklearn.datasets.load_breast_cancer()`
* Samples: **569**
* Features: **30**
* Target Classes:

  * Malignant (0)
  * Benign (1)

---

## 📊 Project Workflow

1. Load the Breast Cancer dataset
2. Convert the dataset into a Pandas DataFrame
3. Explore the dataset

   * Shape
   * Columns
   * Data Types
   * Missing Values
   * Target Distribution
4. Separate Features (X) and Target (y)
5. Perform an 80/20 Train-Test Split
6. Apply Feature Scaling using `StandardScaler`
7. Train a Logistic Regression model
8. Make Predictions
9. Predict Probabilities using `predict_proba()`
10. Interpret Model Coefficients
11. Evaluate the model using:

    * Accuracy
    * Confusion Matrix
    * Classification Report
